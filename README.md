# Rainy Night for Omarchy 4

A blue-grey Omarchy theme inspired by a rainy city at night.

## Requirements

- Omarchy 4.x

## Install

```bash
omarchy theme install https://github.com/MuNeNiCK/omarchy-rainynight-theme.git
```

The installed theme name is `rainynight`. Apply it again at any time with:

```bash
omarchy theme set rainynight
```

Update the installed clone with:

```bash
omarchy theme update
```

## Omarchy 4 compatibility

This fork uses Omarchy 4's semantic `colors.toml` palette. Omarchy generates
terminal, shell, editor, browser, and utility themes from that single palette,
while `hyprland.lua` keeps Rainy Night's gaps, rounding, blur, opacity, borders,
and calm animations.

Based on the original
[atif-1402/omarchy-rainynight-theme](https://github.com/atif-1402/omarchy-rainynight-theme).
